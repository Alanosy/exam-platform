# 2026-09-28

## 考试系统微服务模块划分方案

基于 RuoYi-Cloud-Plus 2.6.2 基座，为考试系统设计了微服务模块划分，产出文档：`docs/考试系统微服务模块划分.md`。

核心结论：
- 核心 6 个模块：`ruoyi-exam-question`(9211, /question/**) 题库、`ruoyi-exam-paper`(9212, /paper/**) 试卷、
  `ruoyi-exam-exam`(9213, /exam/**) 考试、`ruoyi-exam-answer`(9214, /answer/**) 答题判分、
  `ruoyi-exam-mark`(9215, /mark/**) 阅卷、`ruoyi-exam-stat`(9216, /stat/**) 统计。
- 可选 3 个：practice(9217)、cert(9218)、proctor(9219)。
- 小团队精简方案：`ruoyi-exam-core` / `ruoyi-exam-runtime` / `ruoyi-exam-stat` 三域。
- 依赖方向单向：question ← paper ← exam ← answer ← mark，stat 旁路只读。
- 数据源：`ry-exam`（题库/试卷/考试/阅卷）+ `ry-exam-answer`（答卷成绩，独立高并发库）。
- 用户/角色/菜单/权限/租户/日志/文件全部复用框架，只在 `sys_menu` 插菜单数据。

已确认的项目约定（沿用框架）：
- 每个业务服务配一个 `ruoyi-api-xxx`，Dubbo 接口 + DTO/VO；实现 `@DubboService`，调用 `@DubboReference`。
- 模块内结构：controller / domain(bo、vo、convert) / service / mapper，resources 下 application.yml + mapper/。
- 端口占用：9201 system、9202 gen、9203 job、9204 resource、9205 workflow、9210 auth、8080 gateway。
- 网关路由与模块配置在 `script/config/nacos/`，数据源变量在 `datasource.yml`。
