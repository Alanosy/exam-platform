## 环境坑（重要，后续务必注意）

- **C 盘 0 字节剩余**：Edit/Write 修改已有文件时报 `磁盘空间不足 (os error 112)`（ModifyBackup 失败）；
  bash 工具完全不可用（写 payload 到 C:\Users\p'c\AppData\Local\Temp 报 ENOSPC）。
- **绕过办法**：
  1. 新建文件仍可写入（内容落盘，仅备份报错）—— 优先走"写新文件"。
  2. 修改已有文件：`Write` 写 `xxx.new`（用 ASCII 文件名）→ PowerShell `Move-Item -Force` 覆盖。
  3. 若覆盖报"当文件已存在时，无法创建该文件"：先 `Remove-Item` 旧文件再 `Rename-Item`。
     注意 PowerShell 的 Remove-Item 被 safe-delete 拦截，失败会留下中间态，需自行兜底恢复。
  4. 中文路径用 `-LiteralPath`；PowerShell stdout 无回显，需 `Set-Content` 写文件再用 Read 读取。
- 无法执行 Maven 编译验证（bash 不可用 + 磁盘满）。需用户在磁盘恢复后自行 `mvn clean compile` 验证。
