# 2026-09-28

## 试题模块改造（新增/编辑试题支持富文本选项）

**背景**：原来 `views/system/question/index.vue` 只有一个 500px 的小弹窗，只能填题干文本，没法维护选项。
用户要求参考一个 Vue2 的 QuDetail.vue 做如下改造，并明确两点选择：
- 选项数据是**嵌套随试题一次性提交**（不是分开调 /option 接口）
- 编辑形态用**整页表单 + 路由跳转**（不是弹窗/抽屉）

**做的事**：
1. 修复 6 个新模块 api/index.ts 的 types 导入路径（`@/api/xxx/types` → `@/api/system/xxx/types`），
   这是编译致命错误：bank / media / option / question / tag / tagRel。
2. `api/system/question/types.ts` 新增 `QuestionOption`，给 QuestionForm / QuestionVO 加 `options`。
3. 新建 `views/system/question/questionMeta.ts`：题型元数据 + 难度/状态/语言常量 + answer JSON 解析。
   这是整个编辑页的行为开关，支持单选/多选/判断/填空/简答/论述/代码题/文件上传/匹配题 9 种。
4. 新建 `views/system/question/edit.vue`：整页表单，题干与选项都用 Quill 富文本；
   按题型动态渲染答案区（选项列表可增删/排序、填空多可接受答案、代码题语言+参考实现、匹配项）；
   提交前做业务校验（单选/判断只能一个正确答案、多选至少两个、各空的答案非空等）。
5. 重写 `views/system/question/index.vue`：移除旧弹窗，新增/修改跳转路由；题型/难度/状态改成可读标签；
   搜索区支持按题库/题型/难度/状态筛选（加载题库下拉）。
6. `router/index.ts` 增加 hidden 常量路由 `/system/question/edit/:questionId?`（name: QuestionEdit）。
7. `components/Editor/index.vue` 加 `simple`（精简工具栏）和 `placeholder` 两个可选属性，向下兼容。

**验证**：`vue-tsc` 只报这两个文件的 pageNum 必填错误，已修；过滤后新文件零报错。
`npx eslint --fix` 后改动文件零告警。生产构建已跑。

**遗留/需用户确认**：
- 列表页菜单路由地址假设为 `/system/question`，如不符需改 edit.vue 的 `QUESTION_LIST_PATH` 与路由 `activeMenu`。
- 是否同步 question.answer JSON，取决于后端是否也读它（前端现在一定会写）。
- 代码题用的是等宽 textarea，不是 CodeMirror/Monaco；如果要在线高亮/语法校验另说。
